# graph_disc

#### Article:   <small><strong>Quota-constrained matchings in chain graphs: Hall-type characterization and the interval-number complexity boundary</strong>  <a href=""><img src="https://cdn.simpleicons.org/doi/2dd4bf" alt="DOI" height="14" align="absmiddle"></a>  <a href=""><img src="https://cdn.simpleicons.org/zenodo/2dd4bf" alt="Zenodo" height="14" align="absmiddle"></a>  <a href="https://drive.google.com/drive/folders/1HGzCo9WKmTU7dlOZhaCHo8pxqkh0ZxLk?usp=sharing"><img src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/google/google-original.svg" alt="Google Drive" height="14" align="absmiddle"></a></small>

We study exact quota-constrained matchings in Ferrers-ordered chain graphs under laminar, prefix, and interval quotas. We characterize arbitrary laminar quotas by integral flow, prefix quotas by exact demand-capacity inequalities and a canonical $O(n+m)$ algorithm, and one-interval quotas by a shortest-path envelope; interval-number-two quotas are NP-complete. Exhaustive validation and six-procedure comparisons assess correctness, computational cost, memory, energy, and reproducibility.
