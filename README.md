# graph_disc

#### Article:   <small><strong>Quota-constrained matchings in chain graphs: Hall-type characterization and the interval-number complexity boundary</strong>  <a href=""><img src="https://simpleicons.org/icons/doi.svg" alt="DOI" height="14" align="absmiddle"></a>  <a href=""><img src="https://simpleicons.org/icons/zenodo.svg" alt="Zenodo" height="14" align="absmiddle"></a>  <a href="https://drive.google.com/drive/folders/1HGzCo9WKmTU7dlOZhaCHo8pxqkh0ZxLk?usp=sharing"><img src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/google/google-original.svg" alt="Google Drive" height="14" align="absmiddle"></a></small>

We study exact quota-constrained matchings in Ferrers-ordered chain graphs under laminar, prefix, and interval quotas. We prove an integral-flow characterization for arbitrary laminar families, an exact prefix criterion with a canonical $O(n+m)$ algorithm, and a shortest-path envelope for crossing one-interval families, while interval-number-two families are NP-complete. Exhaustive checks, six exact procedures, generalized-regime oracles, resource measurements, and statistical tests assess correctness, computational cost, memory, energy, and reproducibility.
